(1) In the plot-single.png, execution time increasing significantly as the matrix size increases. In plot-multi.png, the execution times are all between 4–5 seconds and do not change very much between runs. CPU usage is also much lower between 17–18%.
(2) plot-taskset.png shows much high CPU usage about 80-90% per process where as plot-single.png much lower between 17–18%. In plot-multi.png, all the processes are running at the same time and can be scheduled across different CPUs. Because they share the available CPU resources, each process only gets around 17–18% CPU, and their execution times are all roughly 4–5 seconds. In plot-taskset.png, all processes are restricted to the CPU 0. The CPU usage is around 80–99%, and the execution time increases with the matrix size, reaching about 4.8 seconds for the 1000×1000 matrix.
